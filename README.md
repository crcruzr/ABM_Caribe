# Simulating Coastal Household Migration in Response to Climate Change

**City focus:** Cartagena  
**Status:** Modelo presentado **22-08-2025**  
**License:** MIT

This repository contains an **Agent-Based Model (ABM)** implemented in **NetLogo** to explore how coastal households may respond to sea-level increase. The current model centers on **Cartagena, Colombia**.
